# SearchEngine

## Описание проекта

**SearchEngine** — учебная поисковая система, разработанная на языке C++.

Программа индексирует набор текстовых документов, принимает поисковые запросы и возвращает наиболее релевантные документы.

Основные возможности проекта:

- загрузка документов из конфигурационного файла;
- построение обратного индекса;
- подсчёт количества вхождений слов в документах;
- выполнение поисковых запросов;
- расчёт относительной релевантности документов;
- сортировка результатов по релевантности;
- ограничение количества результатов поиска;
- сохранение результатов в `answers.json`;
- модульное тестирование основных компонентов программы.

---

## Основные классы

В проекте реализованы три основных класса.

### `ConverterJSON`

Отвечает за работу с JSON-файлами:

- чтение списка документов из `config.json`;
- получение максимального количества результатов;
- чтение поисковых запросов из `requests.json`;
- запись результатов поиска в `answers.json`.

### `InvertedIndex`

Отвечает за построение обратного индекса документов.

Для каждого слова сохраняется список документов, в которых оно встречается, а также количество его вхождений.

### `SearchServer`

Отвечает за выполнение поисковых запросов.

Класс:

- разбивает запрос на отдельные слова;
- ищет документы, содержащие эти слова;
- рассчитывает абсолютную релевантность;
- рассчитывает относительную релевантность;
- сортирует результаты;
- ограничивает количество возвращаемых результатов.

## Стек технологий

Проект разработан с использованием:

- **C++17**
- **CMake 3.20+**
- **MSVC**
- **Ninja**
- **nlohmann/json 3.12.0**
- **GoogleTest 1.17.0**
- **CLion**

Библиотеки `nlohmann/json` и `GoogleTest` автоматически загружаются при конфигурации проекта с помощью `FetchContent`.

Дополнительная ручная установка этих библиотек не требуется.

---

## Запуск проекта

### Требования

Для сборки проекта необходимо:

- CMake 3.20 или выше;
- компилятор с поддержкой C++17;
- Git;
- CLion или другая среда разработки с поддержкой CMake.

Дополнительные библиотеки устанавливать не требуется. `nlohmann/json` и `GoogleTest` автоматически загружаются CMake через `FetchContent`.

### Сборка проекта

Откройте корневую папку проекта в CLion и дождитесь завершения конфигурации CMake.

Также проект можно собрать через терминал из корневой папки:

cmake -S . -B cmake-build-debug
cmake --build cmake-build-debug --target SearchEngine
